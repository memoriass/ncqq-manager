用户管理

权限体系

角色权限值能力
管理员10全部功能：创建/管理容器、管理用户、集群配置、操作日志
普通用户1仅能查看和操作分配给自己的实例

用户操作

  • 创建用户 — 设置用户名、密码（最少 6 个字符）、权限级别
  • 分配实例 — 将容器实例授权给普通用户
  • 重置密码 — 管理员可重置任何用户密码
  • API Key — 每个用户独立的 API 认证密钥，可重新生成
  • 删除用户 — 删除用户账号（不影响容器）

用户面板

普通用户通过 /user 路径访问专属控制台：

  • 查看分配给自己的容器实例，通过 WebSocket 实时推送更新
  • 搜索过滤实例（按名称、QQ 号、状态），支持分页浏览
  • 获取 QR 码扫码登录，点击二维码可放大查看
  • 支持中英文切换和暗色主题

用户面板状态说明

状态标签颜色含义右侧显示
🟢 在线绿色容器运行且 QQ 已登录显示 QQ 头像和号码
🟡 未登录橙色容器运行但需扫码显示 QR 二维码（点击放大）
⚪ 离线灰色容器未运行显示离线图标
