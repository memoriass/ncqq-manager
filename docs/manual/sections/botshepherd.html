BotShepherd 集成

BotShepherd 是一个嵌入式 OneBot v11 协议 WebSocket 代理与管理系统，已集成到 NapCat Manager 中。它统一管理多个 Bot 实例的连接，实现一对多的连接分发、消息统计和跨框架黑名单管理。

🐑 核心能力

  • 连接代理 — 一个 QQ 账号只需一个 WS 连接接入，即可自由连接到多个下游框架（Nonebot/Yunzai/AstrBot/Koishi 等）
  • 消息统计 — 每个账号独立的消息量统计与趋势分析
  • 跨框架黑名单 — 一处拉黑，所有框架生效
  • 指令别名 — 按 Bot/群/全局维度设置指令别名，不同 Bot 可使用不同别名区分业务
  • 群组过滤 — 群管理员可通过过滤词自助禁用指令
  • 触发指令 — 主人在群里可代替其他用户执行指令，支持 at

使用流程

  1. 在管理面板左侧菜单进入 BotShepherd 页面
  2. 首次使用需点击「初始化」按钮，系统会自动安装依赖并创建配置
  3. 初始化完成后点击「启动」按钮启动 BotShepherd 服务
  4. 通过「连接管理」配置上游（NapCat）和下游（框架）的 WebSocket 连接
  5. 通过「账号管理」管理 QQ 账号的配置和在线状态

连接管理

连接是 BotShepherd 的核心概念，定义了消息在 NapCat 和下游框架之间的路由关系。

操作说明
查看连接列出所有已配置的 WebSocket 连接及其状态
编辑连接修改连接地址、Token 等参数
复制连接基于已有连接快速创建新连接
删除连接移除不再需要的连接配置

账号管理

操作说明
查看账号列出所有已注册的 QQ 账号及配置
编辑账号修改账号的黑名单、群组过滤、别名等设置
在线检测检查账号当前的在线状态
删除账号从 BotShepherd 中移除账号

日志查看

BotShepherd 页面底部可查看进程控制台输出（最近 100-500 行），用于排查连接和消息转发问题。

BotShepherd 默认监听端口 5100，可在其配置文件中修改。启动后的 Web 管理界面可通过 http://localhost:5100 直接访问。
BotShepherd 作为子进程随 NapCat Manager 一起启动和停止，Ubuntu 场景无需单独注册 systemd。只需为主项目注册开机自启动，BotShepherd 会在主项目启动时自动唤起。
