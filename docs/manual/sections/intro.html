NapCat QQ Manager

一款基于 FastAPI + React 构建的 NapCat QQ Bot Docker 容器管理面板，提供可视化的容器生命周期管理、多节点集群控制、用户权限分配与实例级文件管理功能。

✨ 核心特性

  • 容器管理 — 一键创建/启动/停止/删除 NapCat Docker 容器
  • QR 码登录 — 实时获取容器内 QQ 登录二维码
  • 多节点集群 — 管理分布在不同服务器上的 NapCat 实例
  • 用户权限 — 管理员/普通用户分级，实例级授权
  • 文件管理 — 在线编辑容器配置文件和插件
  • 网络配置 — 可视化管理 OneBot 11 网络端点
  • 告警监控 — QQ 通知 / SMTP 邮箱 / Webhook 三种渠道，Bot 掉线即时推送
  • 备份恢复 — 配置一键备份与恢复
  • 操作日志 — 全链路操作审计记录
  • Bot 管理 — 消息监控、消息发送、群管理与运行状态透传
  • 安全防护 — CSRF/SSRF 防护、IP 封禁、随机初始密码
  • 中英双语 — 完整的国际化支持
  • 镜像管理 — 列出/拉取/删除本地 Docker 镜像
  • BotShepherd 集成 — 内置 OneBot v11 WS 代理，一键初始化和管理
  • 壁纸资源 — 用户面板自动发现横竖版壁纸

技术栈

层级技术说明
后端Python 3.10+ / FastAPI异步 Web 框架 + Uvicorn ASGI 服务器
前端React 18 / TypeScript / ViteSPA 应用 + Material UI 组件库
数据库SQLite (WAL 模式)轻量级嵌入式数据库，自动迁移
容器aiodocker + docker-py热路径纯异步 Docker API；事件流与 QR 回落保留 docker-py
HTTP 客户端aiohttp异步集群节点通信与登录检测
JSONorjsonWebSocket 热路径高性能序列化（替代 stdlib json）
认证Cookie Session + API Key双模认证，支持 Web 与 API 调用 + CSRF 防护
