容器管理

创建容器

在管理面板中点击"创建容器"按钮，填写以下信息：

字段说明示例
容器名称唯一标识，仅允许字母、数字、连字符、下划线和点号，1-64 字符，以字母或数字开头napcat-bot-01
QQ 账号要登录的 QQ 号123456789
Docker 镜像可选，默认使用全局配置mlikiowa/napcat-docker:latest
创建容器时，系统会自动分配端口并创建数据目录（data/{name}/），包括 QQ 数据、NapCat 配置、插件和缓存四个子目录。

容器操作

操作说明
▶ 启动启动已停止的容器
⏹ 停止正常停止容器
🔄 重启重启容器
🗑 删除删除容器，可选是否同时删除数据目录

容器详情

点击容器卡片进入详情页，包含以下功能标签：

  • 基本信息 — 运行状态、资源用量、QR 码登录
  • 网络配置 — OneBot 11 HTTP/WebSocket/SSE 端点管理
  • 文件管理 — 在线浏览和编辑容器配置文件
  • 日志查看 — 实时查看容器运行日志
  • Bot 管理 — 消息监控、消息发送、群管理与运行状态查看（详见 Bot 管理 章节）

数据目录结构

data/{容器名}/
├── qq_data/        # QQ 数据（挂载到 /app/.config/QQ）
├── config/         # NapCat 配置文件
│   ├── napcat.json           # NapCat 主配置
│   └── onebot11_*.json       # OneBot 网络配置
├── plugins/        # NapCat 插件目录
└── cache/          # 缓存目录
