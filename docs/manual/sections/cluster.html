集群配置

节点管理

NapCat Manager 支持多节点集群部署，可从一个面板管理多台服务器上的容器实例。

本地节点

安装后自动创建 local 节点，指向本机 Docker 引擎。

添加远程节点

  1. 在远程服务器安装 NapCat Manager
  2. 记录远程服务的 地址:端口 和用户管理页面中管理员用户重新生成后显示的 apiKey
  3. 在本机管理面板 → 节点管理 → 添加节点，填入地址和 API Key

新增节点时，节点设置弹窗会自动生成并写入一个节点 api_key；编辑已有节点时可在同一弹窗中查看、复制或重新生成。做节点互联时，两端保存的凭证必须与被访问端实际接受的 Key 一致。

获取生产端 API Key

生产端管理器对外调用使用管理员用户的 apiKey。登录生产端管理面板，进入 用户管理，点击管理员用户卡片中 API Key 右侧的钥匙按钮，确认重置后立即复制保存新 Key。

API Key 属于敏感凭证，页面不会回显已有明文；重置后旧 Key 会失效，已经添加过该生产端的其他管理器节点需要同步更新节点凭证。

密钥体系

存储位置字段作用
SQLite settings 表api_key历史兼容的本机集群通信密钥 — 仍可用于认证，但不作为管理面板推荐获取入口
SQLite nodes 表api_key节点代理凭证 — 本机访问远程节点时携带对方的 Key
SQLite users 表apiKey用户 API Key — 推荐用管理员用户 Key 作为生产端管理器对外调用凭证
远程节点的 api_key 建议填写对方管理器中管理员用户的 apiKey；填写错误会导致代理请求被拒绝（401）。
