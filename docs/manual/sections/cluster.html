集群配置

节点管理

NapCat Manager 支持多节点集群部署，可从一个面板管理多台服务器上的容器实例。

本地节点

安装后自动创建 local 节点，指向本机 Docker 引擎。

添加远程节点

  1. 在远程服务器安装 NapCat Manager
  2. 记录远程服务的 地址:端口 和集群设置页面中重新生成后显示的 api_key
  3. 在本机管理面板 → 节点管理 → 添加节点，填入地址和 API Key

获取生产端 API Key

集群 api_key 属于敏感凭证，页面不会回显已有明文。需要把生产端管理器接入其他节点时，请登录生产端管理面板，进入 集群设置，在“管理器 API Key”区域点击“重置并显示”，立即复制保存新 Key。

重置后旧 Key 会失效，已经添加过该生产端的其他管理器节点需要同步更新节点凭证。若是旧版本部署且必须读取当前已保存的 Key，可在服务器上查询 SQLite：sqlite3 config/app.db "select value from settings where key='api_key';"

密钥体系

存储位置字段作用
SQLite settings 表api_key本机集群通信密钥 — 其他节点访问本机时使用此 Key 认证（可在集群设置页面重置并一次性显示）
SQLite nodes 表api_key节点代理凭证 — 本机访问远程节点时携带对方的 Key
SQLite users 表apiKey用户 API Key — 用于免登录 API 调用认证
远程节点的 api_key 必须与对方节点集群设置中的 api_key 一致，否则代理请求会被拒绝（401）。
