常见问题

Q: 启动后页面显示 "Frontend not built yet"？

A: 前端尚未构建。执行以下命令：

cd frontend && npm install && npm run build

或直接使用快速启动脚本 python start.py 自动构建。

Q: 容器管理页面提示 Docker 连接失败？

A: 检查以下几点：

  • Docker 服务是否正在运行：docker info
  • 当前用户是否有 Docker 权限（Linux 需加入 docker 组）
  • Docker Desktop（Windows/macOS）是否已启动

Q: 如何重置管理员密码？

A: 有两种方式：

  1. 推荐：停止服务 → 删除 config/app.db → 重启服务 → 系统自动生成随机密码的应急管理员（密码会在终端日志中输出一次）→ 登录后立即修改密码
  2. 备选：如果有其他管理员账号，可在用户管理页面重置密码

Q: QR 码一直显示"等待生成"？

A: 可能原因：

  • 容器未运行 — 先启动容器
  • NapCat 尚在初始化 — 等待 10-20 秒
  • WebUI 端口配置错误 — 检查 config/webui.json 中的端口设置

Q: 如何添加远程节点？

A: 参见 集群配置 章节。确保远程节点的 api_key 配置正确。

Q: 支持 HTTPS 吗？

A: 推荐使用 Nginx/Caddy 反向代理配置 HTTPS：

# Nginx 示例（含 WebSocket 支持）
server {
    listen 443 ssl;
    server_name your-domain.com;
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # WebSocket 支持（容器状态推送 + 日志流）
    location /ws/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }
}
使用反向代理时，记得将 CORS_ORIGINS 设置为你的域名，并将 COOKIE_SECURE 设为 true。

Q: 数据保存在哪里？

A: 所有数据位于项目根目录下：

目录/文件内容
config/config.json启动引导配置（initialized / host / port）
config/app.dbSQLite 数据库（用户、会话、节点、运行时设置、操作日志）
data/{容器名}/各容器挂载数据
botshepherd/BotShepherd 子项目（配置、日志、数据库）

Q: BotShepherd 初始化失败怎么办？

A: 可能原因：

  • 网络问题 — BotShepherd 需要安装 Python 依赖，确保能访问 PyPI
  • Python 版本不兼容 — 确保 Python ≥ 3.10
  • 手动初始化 — 进入 botshepherd/ 目录运行 python main.py --setup

Q: 如何手动拉取 Docker 镜像？

A: 除了在管理面板的镜像管理页面操作外，也可以使用命令行：

docker pull mlikiowa/napcat-docker:latest
