Bot 管理

Bot 管理是实例详情页的第五个标签栏，提供对已连接 Bot 的消息监控、消息发送、群管理与运行状态查看功能。所有操作通过管理器的反向 WebSocket 连接代理到目标 Bot 的 OneBot API。

✨ 功能概览

  • 消息监控 — 实时查看 Bot 收到的群聊/私聊消息，支持自动刷新
  • 消息发送 — 通过 Bot 向指定群或好友发送消息
  • 群管理 — 查看 Bot 加入的所有群列表（群号、群名、成员数）
  • 运行状态 — 查看 Bot 的 WS 连接状态、OneBot 版本信息与登录信息

消息监控

消息监控面板展示 Bot 最近收到的消息（环形缓冲区，最多 200 条），包含以下信息：

列说明
时间消息接收时间
类型群聊 / 私聊
发送者群名片或昵称
来源群号或 QQ 号
内容原始消息文本
默认每 5 秒自动刷新消息列表，可手动切换自动/手动模式。消息数据存储在管理器内存中，重启后清空。

消息发送

选择消息类型（群聊/私聊）和目标（群号/QQ号），输入消息内容后发送。消息通过 OneBot send_msg API 代理转发。

请确保 Bot 当前在线（WS 已连接），否则发送将失败。发送频率受管理器速率限制保护。

群管理

通过 OneBot get_group_list API 获取 Bot 加入的所有群信息，包括群号、群名称、当前成员数与最大成员数。

运行状态透传

运行状态面板展示两组信息：

  • 连接信息 — Bot 名称、UIN、昵称、WS 连接状态、最后在线时间（来自管理器 WS 服务层）
  • 版本信息 — 通过 get_version_info API 获取 NapCat 版本、协议版本等运行时信息
  • 登录信息 — 通过 get_login_info API 获取当前登录的 QQ 号与昵称
容器统计接口 /api/containers/{name}/stats 现已包含 bot_ws_connected、bot_nickname、bot_ws_uin、bot_last_seen 字段，可用于外部系统集成或状态监控。

Bot API 端点

方法路径说明
GET/api/bots列出所有已知 Bot
GET/api/bots/{name}/status查询单个 Bot 连接状态
POST/api/bots/{name}/call代理调用任意 OneBot API
POST/api/bots/{name}/send便捷发消息（私聊/群聊）
GET/api/bots/{name}/messages获取最近消息（环形缓冲区）
