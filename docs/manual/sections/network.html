网络配置

网络配置面板提供 OneBot 11 协议端点的可视化管理，支持 HTTP、WebSocket、SSE 等多种通信方式。

端点类型

类型说明用途
HTTP 服务器监听 HTTP 请求接收框架主动调用
HTTP SSE 服务器Server-Sent Events推送事件流
HTTP 客户端主动上报向指定 URL 推送事件
WebSocket 服务器WS 监听双向实时通信
WebSocket 客户端WS 连接主动连接到框架

操作

  • 点击"添加端点"选择类型并填入 URL/端口等参数
  • 编辑已有端点的地址、Token 等配置
  • 删除不需要的端点
  • 保存后自动写入 OneBot 配置文件

后端注入网络配置 API

通过 REST 接口可直接将网络端点配置写入容器的 onebot11_{uin}.json，仅覆盖请求中出现的键，其余键保持不变。

字段值
路径POST /api/containers/{name}/inject-network-config
认证需要管理员 Session Cookie
Content-Typeapplication/json
请求体字段类型说明
uinstring目标账号 UIN，默认 "default"
node_idstring节点 ID，默认 "local"
networkobject网络端点键值，见下方示例
⚠️ 写入时按键覆盖：network 内每个键的值会整体替换原文件中对应键的列表，不做追加合并。

五种端点配置 JSON 参考

以下示例均为完整 network 对象中的单个端点配置，可按需组合传入。

① WebSocket 客户端（最常用 — 主动连接到 Bot 框架）

{
  "uin": "123456789",
  "network": {
    "websocketClients": [
      {
        "name": "主框架",
        "enable": true,
        "url": "ws://127.0.0.1:8080/onebot/v11/ws",
        "token": "your_access_token",
        "reportSelfMessage": false,
        "messagePostFormat": "array",
        "debug": false,
        "heartInterval": 30000,
        "reconnectInterval": 5000
      }
    ]
  }
}

② WebSocket 服务器（监听 WS 连接，框架主动连入）

{
  "uin": "123456789",
  "network": {
    "websocketServers": [
      {
        "name": "WS服务端",
        "enable": true,
        "host": "0.0.0.0",
        "port": 3001,
        "token": "your_access_token",
        "reportSelfMessage": false,
        "messagePostFormat": "array",
        "debug": false,
        "heartInterval": 30000
      }
    ]
  }
}

③ HTTP 服务器（接收框架的 API 调用）

{
  "uin": "123456789",
  "network": {
    "httpServers": [
      {
        "name": "HTTP服务端",
        "enable": true,
        "host": "0.0.0.0",
        "port": 3000,
        "token": "your_access_token",
        "enableCors": false,
        "enableWebsocket": false,
        "messagePostFormat": "array",
        "debug": false
      }
    ]
  }
}

④ HTTP 客户端（主动上报事件到指定 URL）

{
  "uin": "123456789",
  "network": {
    "httpClients": [
      {
        "name": "事件上报",
        "enable": true,
        "url": "http://127.0.0.1:5700",
        "token": "your_access_token",
        "reportSelfMessage": false,
        "messagePostFormat": "array",
        "debug": false
      }
    ]
  }
}

⑤ HTTP SSE 服务器（Server-Sent Events 推送事件流）

{
  "uin": "123456789",
  "network": {
    "httpSseServers": [
      {
        "name": "SSE推送",
        "enable": true,
        "host": "0.0.0.0",
        "port": 3002,
        "token": "your_access_token",
        "reportSelfMessage": false,
        "messagePostFormat": "array",
        "debug": false
      }
    ]
  }
}
