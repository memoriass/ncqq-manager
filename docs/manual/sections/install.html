安装部署

环境要求

组件版本要求用途
Python≥ 3.10后端运行时
Node.js≥ 16前端构建（仅部署时需要）
Docker≥ 20.10容器管理功能
操作系统Windows / Linux / macOS均支持

方式一：Docker Compose 部署（推荐）

# 获取源码
git clone https://github.com/your-repo/ncqq-manager.git
cd ncqq-manager

# 一键启动（自动构建镜像并运行）
docker compose up -d
Docker Compose 会自动构建前端、安装依赖并启动服务。数据持久化在 config/ 和 data/ 目录。镜像内置 HEALTHCHECK 自动检测服务健康状态。

方式二：手动安装

1. 获取源码

git clone https://github.com/your-repo/ncqq-manager.git
cd ncqq-manager

2. 安装 Python 依赖

# 推荐使用虚拟环境
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt

3. 构建前端

cd frontend
npm install
npm run build
cd ..
构建完成后会生成 frontend/dist/ 目录，后端自动挂载为静态资源。

4. 启动服务

# 方式一：使用快速启动脚本
python start.py

# 方式二：直接启动
python main.py

# 方式三：使用 uvicorn
uvicorn main:app --host 0.0.0.0 --port 8000

6. Ubuntu systemd 自启动（uv）

# 首次部署建议先手动启动一次，完成依赖安装、前端构建与初始化
uv run python start.py

# 注册开机自启动（仅注册主项目）
sudo bash scripts/install_autostart_ubuntu.sh

# 卸载开机自启动
sudo bash scripts/uninstall_autostart_ubuntu.sh
systemd 服务仅注册 NapCat Manager 主进程。BotShepherd 不单独注册，由主项目在启动时自动唤起。

5. 访问面板

浏览器打开 http://localhost:8000，首次访问将引导您设置管理员账号。

请确保 Docker 服务已启动，否则容器管理功能将不可用。
