API 接口

NapCat Manager 提供 RESTful API，支持通过 API Key 进行免登录认证调用。

认证方式

在请求中携带 API Key 即可认证：

# 方式一：Header
curl -H "x-request-api-key: YOUR_API_KEY" http://localhost:8000/api/containers

# 方式二：Query 参数
curl http://localhost:8000/api/containers?apikey=YOUR_API_KEY

主要端点

方法路径说明认证
GET/api/public/containers公开容器列表（QQ号/状态）无需
GET/api/containers/{name}/qrcode获取 QR 登录二维码无需
GET/api/containers容器列表（完整信息）登录
POST/api/containers创建容器管理员
POST/api/containers/{name}/action容器操作（start/stop/restart/delete）登录
GET/api/containers/{name}/stats容器统计信息（含 last_event 字段，见下方说明）登录
GET/api/containers/{name}/events实例事件 SSE 流（start/stop/die 等生命周期事件）登录
GET/api/containers/{name}/files文件/目录列表（?path= 指定子目录）登录
POST/api/containers/{name}/config/{filename}保存文件内容登录
DELETE/api/containers/{name}/files删除文件或目录（?path= 必填，禁止删根目录）登录
GET/api/containers/{name}/logs容器日志登录
GET/api/nodes节点列表管理员
GET/api/users用户列表（分页）管理员
GET/api/alerts/settings告警全局设置管理员
PUT/api/alerts/settings更新告警设置（允许所有 IP 等）管理员
GET/api/operation_logs操作审计日志管理员
GET/api/images本地 Docker 镜像列表管理员
POST/api/images/pull拉取 Docker 镜像管理员
DELETE/api/images/{image_id}删除本地镜像管理员
GET/api/bots列出所有已知 Bot（WS + 容器合并）登录
GET/api/bots/{name}/status查询单个 Bot 连接状态登录
POST/api/bots/{name}/call代理调用 OneBot API（透传 action/params）登录
POST/api/bots/{name}/send便捷发消息（私聊/群聊）登录
GET/api/bots/{name}/messages获取 Bot 最近消息（环形缓冲区）登录
GET/api/botshepherd/statusBotShepherd 运行状态管理员
POST/api/botshepherd/setup初始化 BotShepherd管理员
POST/api/botshepherd/start启动 BotShepherd管理员
POST/api/botshepherd/stop停止 BotShepherd管理员
GET/api/botshepherd/connections连接列表管理员
GET/api/botshepherd/accounts账号列表管理员
GET/api/resource/wallpapers壁纸资源列表无需
POST/api/auth/login登录无需
GET/api/health健康检查无需
完整 API 文档可访问 http://localhost:8000/docs（FastAPI 自动生成的 Swagger UI）。
