文件管理

文件管理器允许您在线浏览和编辑容器的配置文件，无需 SSH 连接到服务器。

功能

  • 目录浏览 — 面包屑导航，支持多层目录的文件夹与文件展示
  • 文件编辑 — 在线编辑 JSON/YAML/文本配置文件，带等宽字体代码框
  • 保存修改 — 编辑后直接保存到容器挂载的数据目录
  • 文件删除 — 文件与文件夹均可删除，操作前弹出确认对话框，删除文件夹时递归移除所有子内容，不可撤销
所有文件操作通过已鉴权的 API 端点 /api/containers/{name}/files 进行，确保安全性。根目录禁止删除，所有路径经过服务端安全校验防止目录穿越，危险操作记录于操作审计日志。
