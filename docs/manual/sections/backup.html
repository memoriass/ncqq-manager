备份恢复

备份功能允许管理员导出和恢复管理器配置，以及各实例的 data/{实例名}/config/ 配置目录。

操作说明

功能说明
下载备份导出 config/ 与 data/{实例名}/config/ 为 .zip 文件，不包含运行时资源与 qq_data
上传恢复上传之前导出的 .zip 文件覆盖当前配置目录，需要重启生效
备份信息查看当前备份范围的大小和最后修改时间
上传的备份文件最大不超过 200 MB，且必须为 .zip 格式。恢复操作会覆盖当前 config/ 与 data/{实例名}/config/ 内容，请确认后再操作。
运行时生成的协议缓存、资源文件、qq_data 等内容不会进入备份，恢复后由协议端自动重新生成。
